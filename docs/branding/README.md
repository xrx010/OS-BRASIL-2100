# Branding

## Identity
The Brasil 2100 ecosystem should communicate a modern, institutional, public-interest identity rooted in strategic planning, knowledge systems, and civic trust.

## Visual direction
- strong institutional typography
- neutral and credible palette
- clear governance and planning language
- emphasis on public impact and long-term future

## Positioning
Genesis is the digital infrastructure layer behind the Brasil 2100 strategic agenda, while the institutional and municipal layers translate this vision into action.
