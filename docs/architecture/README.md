# Architecture

## Overview
This repository is organized as a modular monorepo for the Genesis ecosystem and the Brasil 2100 institutional agenda.

## Layers
- platform core: kernel, builder, core, registry
- module layer: atlas, edu2100, future modules
- institutional layer: constitution, institute, municipalities
- documentation layer: docs, branding, roadmap

## Principles
- modularity
- maintainability
- reproducibility
- governance traceability
- public value
