# Município Piloto

## Objetivo
Servir como laboratório institucional para validar a adoção do ecossistema Genesis em contexto municipal.

## Escopo
- diagnóstico territorial
- planejamento estratégico
- indicadores públicos
- integração com dados e plataformas locais
- apoio à governança e transparência

## Cadência
O piloto deve operar com documentação clara, dados mapeados e indicadores de progresso publicados periodicamente.
